# Technic-AI

Intelligent computer vision assistant for technical drawing and geometric analysis.

##  Objective
Develop a web application that analyzes images of technical blueprints, detects geometric elements (lines, angles, shapes), and assists students in learning technical drawing concepts.

## 🛠️ Tech Stack & Tooling
- **Backend & Computer Vision**: Python 3.12+, OpenCV, Tesseract OCR, SymPy, `ezdxf`, `pytest`
- **Frontend**: HTML5, CSS3, JavaScript
- **Methodology & AI Tooling**: Spec-Driven Development, Model Context Protocol (MCP), Engram, Cursor, Google Docstrings
- **Deployment**: Vercel
